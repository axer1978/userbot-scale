# userbot-scale

Telegram and WhatsApp AI support assistant: userbots for many accounts
(Telethon for Telegram; a linked device through Baileys for WhatsApp), run by
a Docker Compose stack (panel, manager, scheduler, wa-gateway, Postgres,
Valkey) with one password-protected web admin panel. See
[`telegram_admin_bot/README.md`](telegram_admin_bot/README.md) for deployment
and operation.
